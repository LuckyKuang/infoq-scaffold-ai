# 选择器策略

## 优先级

1. 可访问名称：按钮文本、表单 label、菜单文本。
2. 稳定业务文本：表格列名、弹窗标题、模块标题。
3. 稳定属性：已有 `data-*` 或组件库可访问属性。
4. 结构选择器：仅在没有稳定语义时使用，并限制在局部容器内。

## React / Ant Design

- 优先使用按钮文本、表单 label、表格列名。
- 对弹窗使用标题和按钮组合定位。
- 不依赖 Ant Design 生成的动态 class。

## Vue / Element Plus

- 优先使用按钮文本、表单 label、表格列名。
- 对 `el-dialog` 使用标题和确认/取消按钮组合定位。
- 不依赖 Element Plus 生成的动态 class。

## 稳定性要求

- 同一个模块的 React/Vue 选择器策略应尽量一致。
- 如果必须使用结构选择器，应在测试代码附近说明原因。
- 不为了测试加入无意义 DOM 标记；若确需 `data-testid`，应作为产品可测试性改造单独评估。
