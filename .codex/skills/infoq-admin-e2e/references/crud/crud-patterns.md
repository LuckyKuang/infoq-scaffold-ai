# CRUD E2E 模式

## 查询

适用：列表页、日志页、配置页。

步骤：

1. 完成真实登录或复用已登录态。
2. 打开目标模块路由。
3. 等待表格、树或配置面板出现。
4. 输入查询条件。
5. 点击查询。
6. 断言结果区域刷新，且无阻断性 console error。

## 新增

适用：用户、角色、部门、岗位、字典、公告、客户端、邀请码等。

步骤：

1. 使用 `e2e_` 前缀生成唯一测试数据。
2. 打开新增弹窗或页面。
3. 填写必填项。
4. 提交。
5. 断言成功提示和列表可查。
6. 记录 cleanup 主键或唯一键。

## 编辑

步骤：

1. 先创建或定位 `e2e_` 测试数据。
2. 打开编辑入口。
3. 修改非关键字段。
4. 提交。
5. 断言列表、详情或接口结果更新。

## 删除

步骤：

1. 只删除当前用例创建的 `e2e_` 数据。
2. 触发删除并确认。
3. 断言列表不可再查。
4. 删除失败时输出人工回滚提示。

## 导入导出

- 导入必须使用临时文件并在 `doc/tmp/` 下留存。
- 导出必须断言文件响应或下载事件。
- 不得把下载文件散落到仓库根目录。

## 权限按钮

每个模块至少设计两类断言：

- 有权限账号：按钮可见且可触发。
- 无权限账号：按钮不可见或触发后被拒绝。

如多账号矩阵尚未建立，先记录为延期，不伪造权限覆盖。
